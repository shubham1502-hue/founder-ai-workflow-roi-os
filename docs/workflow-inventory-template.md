# Workflow Inventory Template

Use this template before editing the CSV.

## Required fields

| Field | What to capture | Example |
| --- | --- | --- |
| Workflow ID | Stable ID | WF-001 |
| Function | Owning function | Sales |
| Workflow name | Short name | Summarize sales calls |
| Owner role | Current owner | Account Executive |
| Current tooling | Tools used today | Zoom, HubSpot, Google Docs |
| Workflow description | What happens today | Summarize calls and update CRM |
| Frequency per month | How often it runs | 35 |
| Average time per run | Minutes per run | 20 |
| People involved | People per run | 1 |
| Error rate | Estimated percent with rework | 10 |
| Monthly volume | Units processed | 35 calls |
| Business impact | 1 to 5 score | 4 |
| Customer impact | 1 to 5 score | 4 |
| Data sensitivity | Low, medium, high | Medium |
| Process variability | Low, medium, high | Low |
| Current pain | Low, medium, high | High |
| Current cost signal | Low, medium, high | Medium |
| Automation idea | AI or automation idea | Draft call summary and CRM fields |
| Requires human judgment | Yes or no | No |
| Current status | Documented, partial, ad hoc, chaotic | Documented |

## Practical collection questions

Ask each team lead:

- What recurring work takes too much time?
- What gets delayed because nobody owns it clearly?
- What work creates rework or mistakes?
- What work is repetitive but still done manually?
- What customer-facing work should never ship without review?
- What finance, hiring, legal, or investor work needs extra approval?
- What could be assisted by templates, summaries, routing, drafts, or checklists?

## Scoring guidance

Use simple estimates:

- `1` means low impact.
- `3` means moderate impact.
- `5` means high impact.

For risk fields:

- `low` means repeatable and low sensitivity.
- `medium` means some exceptions or some sensitive data.
- `high` means sensitive, variable, judgment-heavy, or costly if wrong.
